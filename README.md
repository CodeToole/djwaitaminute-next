# DJ Waitaminute — Official Site

Next.js + TypeScript site for DJ Waitaminute (Drum & Bass).

## Run locally

```bash
git clone https://github.com/CodeToole/djwaitaminute-next.git
cd djwaitaminute-next
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Notes

- Place `djwaitaminutevisz.mp4` in `public/media/` for the hero video.
- Logo images go in `public/` (logo-wordmark.jpg, logo-icon.jpg, logo-car.jpg).
